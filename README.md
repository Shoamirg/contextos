# ContextOS

Visual operating system for managing work contexts, browser tabs, and resources.

Local-first. Privacy-first. Open-source.

## Development

```bash
npm install
npm run typecheck
npm run test
npm run build
```

Extras:

```bash
npm run lint
npm run test:watch
```
