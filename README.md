# ContextOS

Visual operating system for managing work contexts, browser tabs, and resources.

Local-first. Privacy-first. Open-source.

## Getting started

```bash
npm install
npm run build
```

Load the unpacked extension from `dist/` in Chrome/Edge/Brave.
